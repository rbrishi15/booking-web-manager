# Singapore region boundaries

`singapore-regions.json` contains all five unmodified MultiPolygon geometries
and REGION_N values from URA's Master Plan 2019 Region Boundary (No Sea),
dataset `d_bf4d24df9129d5a8ff8cf82e20959ee0`, downloaded on 2 October 2026.
Unused properties are omitted; coordinate precision is preserved. This file is
server-only and does not add a runtime data.gov.sg dependency.

Source: https://data.gov.sg/datasets/d_bf4d24df9129d5a8ff8cf82e20959ee0/view
Licence: https://data.gov.sg/open-data-licence

These are indicative planning boundaries. Points outside the polygons or on a
boundary shared by two regions return no region, so the user chooses manually.
