# Mobile navigation icons

These SVGs are the original exported assets from the
[SC2006 Home V3 action bar](https://www.figma.com/design/PBywTYV9pSSJQwVkQOy1tx/SC2006?node-id=2116-12392).
They are bundled locally, without temporary Figma asset URLs in the application.

Home, Sessions, Wallet and Settings retain their native 20 × 20 dimensions.
The divider is 1 × 20. All assets are decorative: each link's text provides its
accessible name, with only the current destination's label visually expanded.
Dark mode inverts the icons for contrast; the SVG files themselves are unchanged.
