# Court background

`mobile-hero.png` is the user-provided **Hero BG-2.png**, copied without changing
its pixels (1109 × 604). It is decorative and uses empty alternative text.

The mobile shell follows the background layers in the
[SC2006 Home V3 Figma frame](https://www.figma.com/design/PBywTYV9pSSJQwVkQOy1tx/SC2006?node-id=2116-12358),
background group `2117:14027`: a centered, oversized image with 50% opacity,
a horizontal fade toward the left, and a vertical fade into the page surface.
The image is reduced to 15% opacity in dark mode, and the fades use the theme's
card surface instead of hardcoded white.

The desktop shell reuses the same image behind the page introduction in a
420px-high region, with theme-aware horizontal and vertical fades. Its opacity
is reduced in dark mode so foreground text and controls retain their contrast.

The separate [sport photos](sports/README.md) remain the discovery card imagery.
